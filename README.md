## 🎨 Sobre o projeto
Esse projeto nasceu da vontade de transformar minha paixão por música — especialmente pelo Rock — em algo visual e interativo. Queria ir além de listas de reprodução, quis criar uma jornada que celebrasse as eras mais marcantes desse gênero imortal.  Assim surgiu o **ROCK THROUGH THE AGES:** um site que apresenta a história do Rock and Roll por meio de playlists cuidadosamente curadas,  com uma estética que também dialoga com o místico, o simbólico e o atemporal.

A ideia de representar cada era como uma "carta-relíquia" inspirada em baralhos de tarô moderno surgiu logo no início. Quis dar a cada fase da história do rock uma identidade visual própria, com texturas, cores, elementos e símbolos que remetessem não só à música da época, mas também aos sentimentos e transformações culturais que ela carregava.

Além do lado criativo, esse projeto foi um espaço de muito aprendizado técnico também. Reforcei meus conhecimentos em React, componentes reutilizáveis, responsividade, uso de playlists incorporadas via iframe e deploy no GitHub Pages. 

Durante o processo, explorei conceitos fundamentais do React, como: 
- 🎯 Componentização com componentes reutilizáveis
- 🎯 Uso de `props` para dinamismo dos cards
- 🎯 `useState` para controle de interação
- 🎯 Renderização condicional de conteúdo
- 🎯 Estilização modular e responsiva
- 🎯 Integração com serviços externos (Spotify Embed)
- 🎯 Deploy via GitHub Pages

Foi também a primeira vez que explorei com mais profundidade a ideia de integrar arte gerada por IA com desenvolvimento web — e essa combinação se mostrou não só viável, como inspiradora.

Acima de tudo, esse projeto me ensinou que desenvolver pode ser uma forma de contar histórias. E essa é uma das minhas favoritas.

## 📸 Imagens do Projeto
As imagens são representações artísticas feitas com apoio de inteligência artificial e inspiradas em cartas de tarô modernas, adaptadas a cada fase histórica desse gênero que é, também, um eco perpétuo da rebeldia.

## 🧠 Sobre a criação das imagens com IA
Uma das propostas iniciais do projeto foi trazer uma estética mística e simbólica às eras do rock, como se fossem cartas de um tarô musical. Cada imagem foi concebida a partir de diretrizes visuais cuidadosamente pensadas por mim — com elementos simbólicos, padrões inspirados em baralhos e estética esotérica — e geradas com o apoio do ChatGPT, que traduziu essas ideias em imagens utilizando ferramentas de inteligência artificial.

Essa escolha busca reforçar o caráter atemporal do Rock como um arquétipo cultural.


## ⚙️ Instalação
Para rodar localmente:
```bash
# Clone o repositório
git clone https://github.com/ssaralopes/playlist.git

# Entre na pasta do projeto
cd playlist

# Instale as dependências
npm install

# Rode localmente
npm start
```
